Previsão de inadimplência no cartão

Modelo que estima o risco de cada cliente e explica os fatores por trás da inadimplência.

Python, SQL, modelo de classificação, SHAP, Power BI

Problema

A empresa sabia que a inadimplência no modelo cartão era alta, mas não sabia o motivo nem quais perfis de cliente concentravam o risco.

O que fiz

Extraí os dados direto do banco e cruzei os clientes inadimplentes com os planos contratados e as características de cada contrato. Treinei um modelo de classificação para estimar o risco por cliente e usei SHAP para explicar os fatores que mais pesam. Entreguei ao gestor as causas encontradas e recomendações.

Resultado

Causas da inadimplência e perfis de maior risco identificados, com recomendações entregues ao gestor.

Conciliação de notas fiscais

Automação mensal que compara o portal governamental com a base interna e aponta as notas faltantes.

Python, SQL Server, Power BI, Figma

Problema

A contabilidade conferia cerca de 500 notas por ciclo, uma a uma, entre o portal governamental e a base interna, porque alguns documentos não chegavam até ela. O processo levava semanas.

O que fiz

Desenvolvi uma automação em Python que integra o portal e a base interna, trata os dados e identifica as notas presentes no portal e ausentes na base. Validei a consistência com consultas no SQL Server e criei um dashboard no Power BI, com a interface planejada no Figma. O processo roda sozinho todo mês.

Resultado

Pendências identificadas no mesmo dia, em vez de semanas.

Integração de dados entre sistemas

Fluxo automático que leva os dados do ERP para outro sistema, sem trabalho manual.

SQL, integração por banco, agendamento com log e alerta

Problema

Os dados do ERP precisavam ser levados manualmente para outro sistema, um processo repetitivo, sujeito a erro e que atrasava a visualização das informações.

O que fiz

Estruturei views em SQL com regras e campos padronizados e configurei a integração por arquivo e por banco. Agendei a execução automática com log e alerta de falha e documentei o processo de ponta a ponta.

Resultado

O processo manual virou um fluxo automatizado, com dados disponíveis para visualização sem intervenção.

Pipeline ETL para gestão de coletas de resíduos

Pipeline que transforma as solicitações de coleta em dados confiáveis para a logística.

Python, Pandas, MySQL, Apache Airflow, Docker, AWS S3, SQL

Problema

Em um cenário próximo ao de operações logísticas, a equipe precisava de uma base consistente, a partir de dados brutos, para planejar, acompanhar e otimizar as rotas diárias de coleta.

O que fiz

  • Armazenei o arquivo de origem na AWS S3 e automatizei a extração com Python.
  • Tratei e validei os registros com Pandas, identificando campos obrigatórios ausentes, pesos inválidos e outros erros de qualidade.
  • Importei apenas os registros válidos para o MySQL e registrei cada execução em uma tabela de log, para monitoramento e rastreabilidade.
  • Orquestrei o pipeline com Apache Airflow em Docker.
  • Desenvolvi o protótipo da interface, com visão centralizada das coletas, do status das solicitações, da operação dos caminhões e do gerenciamento dos clientes.

Solução de BI completa

Arquitetura de dados de ponta a ponta para uma operação fictícia de varejo, do banco transacional ao Power BI.

SQL Server, T-SQL, SSIS, Data Warehouse, Star Schema, Power BI, DAX

Problema

Os dados da operação ficavam no ambiente transacional, e faltava uma camada analítica, com qualidade e histórico, para apoiar a tomada de decisão.

O que fiz

  • Modelei o banco relacional (OLTP) no SQL Server, nos níveis lógico e físico.
  • Criei a camada Stage para isolar, tratar e padronizar os dados.
  • Implementei os ETLs em SSIS, com regras de qualidade e área dedicada para auditoria de erros (BI_ERROR).
  • Construí o Data Warehouse em Star Schema, com tabela fato, dimensões analíticas e SCD Tipo 2 para preservar o histórico.
  • Desenvolvi a carga incremental com T-SQL e a técnica de watermark.
  • Criei análises, KPIs e dashboards interativos no Power BI.
