Agente de IA para automação de cobranças

Agente que entende pedidos em linguagem natural e consulta inadimplências e pagamentos.

Python, FastAPI, MySQL, tool calling
  • Interpreta solicitações em linguagem natural e escolhe a ferramenta certa para cada pedido (tool calling).
  • Integração com MySQL para consultar inadimplências e dados de pagamento e executar ações de cobrança.
  • Fluxo human-in-the-loop: pede confirmação do usuário antes de qualquer ação sensível.
  • Disponibilizado como API REST com FastAPI.
